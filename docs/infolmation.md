5. Contabilidad
El módulo Contabilidad debe cubrir los siguientes requerimientos funcionales:
❖ La Contabilidad se maneja por periodos contables, que habitualmente van de Enero a
Diciembre de cada año.
❖ El plan de cuentas contables es definido por el equipo de Contabilidad de la
empresa, que podría variar de un periodo a otro.
❖ Se debe considerar que las cuentas contables pueden ser definidas como
Imputables y No imputables (o Asentables y No Asentables), pueden haber
diferentes niveles de anidamiento para las cuentas contables.
❖ Los asientos contables deben cumplir con el principio de partida doble, es decir,
la suma de las cuentas que afectan al debe, necesariamente deben coincidir con
la suma de las cuentas que afectan al haber.
❖ Los asientos deben ser generados de manera automática desde cada módulo que
tiene el Sistema.
❖ Para que puedan generarse de manera automática, el módulo de contabilidad
debe proveer una estructura de modelos de asientos para cada módulo que
generará su asiento correspondiente.
❖ Considerar que también pueden ser registrados asientos de manera manual para
casos puntuales.
❖ Los datos referentes a cuentas contables y asientos, pueden ser modificados
mientras el proceso correspondiente al periodo contable se encuentre habilitado.
❖ El módulo de Contabilidad debe proveer los siguientes informes básicos:
o Libro Diario
o Libro Mayor
o Balance General
o Balance de Sumas y Saldos
o Balance de Resultados
